## 📘 What is React?

**React** is a JavaScript library developed by Facebook for building fast and interactive user interfaces (UIs).  
It uses a **component-based architecture**, allowing developers to create reusable UI pieces.

### ✨ Key Features:
- Declarative UI
- Virtual DOM for performance
- Reusable Components
- JSX syntax
- One-way data binding
- React Hooks (for state and lifecycle)
- Rich ecosystem and community support

---

## ⚡ What is Vite?

**Vite** (pronounced "Veet") is a next-generation front-end build tool that is extremely fast and lightweight.  
It’s an alternative to **Create React App (CRA)** and provides faster startup and Hot Module Replacement (HMR).

### 🚀 Advantages of Vite:
- Lightning-fast dev server
- Instant Hot Reload
- Smaller bundle size
- Built-in TypeScript support
- Easy configuration
- Uses **ES Modules (ESM)**
